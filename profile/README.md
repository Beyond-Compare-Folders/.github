## Inside Beyond Compare

Beyond Compare is a local Windows compare app with a named compare desk, a short pair list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside folders you already own and holds only the pair that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra pairs wait for their own title. Beyond Compare starts with a local profile and does not need a complex account system.

The compare desk stays on folders you already keep. Untitled pairs stay off the live list.
